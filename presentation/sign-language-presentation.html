Problem Statement
Why this matters
  • Deaf/hearing communication gap in daily life
  • Lack of accessible, interactive learning tools
  • Existing systems either heavy or not real-time
Goal

Create a fast, accurate, and usable system for both learning and live interpretation.

Objectives
  • Detect core gesture vocabulary reliably (Top-1 ≥ 90%)
  • Interactive Learn Mode with voice feedback
  • Compact models for edge deployment
  • Clean UX & privacy-first design
Evaluation

Accuracy, latency, confusion analysis, and user study for satisfaction.

Related Work
Existing approaches
  • Raw image CNNs (accurate, heavy)
  • 3D convnets for sequences (accurate, slow)
  • Landmark-based systems: efficient, explainable
Our contribution

Hybrid pipeline: landmarks + light temporal model + reliable heuristics for core gestures.

System Architecture
Overview

Client captures webcam frames, extracts landmarks, then classification runs locally with optional cloud fallback for heavy models.

Architecture diagram
Hand Landmarks (MediaPipe)
Definition

MediaPipe provides 21 landmarks indexed 0..20. We use those to compute finger extension, relative distances and angles for robust classification.

21-point hand diagram
Features & Augmentation
Features
  • Normalized distances & angles between key joints
  • Finger extension booleans
  • Temporal smoothing & buffering
Augmentations
Flip, scale, brightness jitter, temporal cropping — applied to frames & landmark noise simulation (make model robust).
Classification Pipeline
Hybrid approach

Fast rule heuristics for obvious gestures; temporal model (light Transformer / BiLSTM) for ambiguous sequences. Quantize model for edge deployment.

Pipeline visual
Dataset
Composition
  • Custom collected recordings from multiple signers
  • Augmented with public ASL subsets
  • Per-frame landmark + class labels
Labeling & quality

Quality checks, consensus labeling for ambiguous gestures, test/train split with signer separation to measure generalization.

Training & Optimization
Training
  • Quantization-aware training
  • Knowledge distillation for tiny models
  • Early stopping & weighted loss for class imbalance
Model size & latency

Target: < 2MB model (TFLite) and inference ≤50ms on edge prototype.

Backend (Flask)
Key routes
  • /video_feed — multipart MJPEG stream
  • /gesture — returns latest label JSON
  • /start_camera / /stop_camera for control
